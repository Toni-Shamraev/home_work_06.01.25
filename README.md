# Домашняя работа по теме "Продвинутый Git"

## Описание:

Домашка содержит файл processing.py в котором реализованы две функции согласно тз.

## Использование:

1. Измените значение ключа state в списке словарей bank_operations.
2. Запустите код, консоль выведит либо значение по умолчанию, либо "CANCELED" из первой функции
3. Из второй функции выведит отсортированый список по дате.
